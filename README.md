# Клёвый English — файлы для загрузки

Большие файлы для игры «Клёвый English», которые она скачивает сама (Настройки → Загрузки):

- `voices-us-*.zip`, `voices-uk-*.zip` — озвучка слов, примеров и диалогов, записанная нейросетевым голосом [Kokoro](https://github.com/hexgrad/kokoro) (Apache 2.0);
- `speech-*.zip` — офлайн-модель распознавания речи [Vosk small English 0.15](https://alphacephei.com/vosk/models) (Apache 2.0);
- `manifest.json` — версии и размеры, по нему игра понимает, что обновить.

Файлы обновляются автоматически из сборки игры. Кода игры здесь нет.
